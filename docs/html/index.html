#학습 사이트 (HTML)

이 문서들을 학습 순서대로 묶은 웹사이트 스냅샷이 docs/html/에 있습니다. 브라우저로 docs/html/index.html을 열면 서버 없이 동작합니다(검색, 목차, 다크 테마, 읽음 표시).

  • md가 원본입니다. 평소에는 md만 고치고, 필요한 시점에 npm run docs:html로 스냅샷을 다시 만듭니다.
  • 마지막 스냅샷 이후 바뀐 문서는 npm run docs:html:status로 확인합니다.
  • 구조, 갱신 절차, 문제 해결: 사이트 관리 가이드

#문서 작성 규칙

  • 새 문서나 갱신한 문서 상단에 > 최신화 기준: YYYY-MM-DD · <branch> <commit>을 적습니다.
  • 코드 경로는 실제 존재하는 경로만 링크합니다. 파일을 이동하거나 삭제하면 관련 문서도 같은 PR에서 고칩니다.
  • 결정이 필요한 정책은 music/decisions.md 또는 최신 감사 리포트 로드맵에 적습니다. AI 작업 프롬프트는 docs에 두지 않습니다.
  • 감사 리포트는 날짜별 새 파일로 추가하고, 이전 리포트는 이력으로 남깁니다. 같은 감사의 후속 조치는 리포트 끝에 장을 추가해 기록합니다.
  • learning/은 개념과 이유, deployment/는 실행 절차를 담습니다. 같은 주제는 두 문서가 서로 링크합니다.
  • HTML 사이트는 md에서 생성합니다. docs/html/의 .html은 고치지 않습니다. 새 문서는 docs/html/_tools/site.config.json에 넣어 학습 순서를 정합니다.
  • 링크와 앵커는 CI(npm run docs:html:verify)가 매 PR 검사합니다. 깨지면 CI가 실패합니다.

이 페이지는 docs/README.md에서 생성했습니다. 내용을 고칠 때는 원본 md만 수정합니다(사이트 관리).
